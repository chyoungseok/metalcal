# Metal Calendar (메탈 캘린더)

기기 안에만 데이터가 저장되는 개인용 캘린더 PWA. 서버·계정·광고·추적 코드 없음.
안드로이드 · 아이폰/아이패드 · 맥 · 윈도우에서 같은 파일로 동작합니다.

## 왜 PWA인가 — 무기한 무료
- 앱스토어 등록비(애플 연 $99 등)나 구독료가 없습니다. 코드는 순수 HTML/CSS/JS 정적 파일이고 전부 내 소유입니다.
- 정적 파일 호스팅은 무료 서비스로 충분합니다 (아래 참고). 호스팅 업체가 바뀌어도 이 폴더를 그대로 다른 곳에 올리면 됩니다.
- 한 번 설치하면 오프라인에서도 동작합니다 (서비스 워커 캐시).

## 데이터 보안 구조
- 일정은 각 기기 브라우저의 **IndexedDB**에 저장됩니다. 호스팅 서버는 앱 파일만 전달할 뿐 데이터를 볼 수 없습니다.
- **기기 간 동기화(선택)**: 기기에서 **동기화 코드로 암호화(AES-256-GCM)한 뒤** 내 동기화 서버에 보관합니다. 서버에는 해독할 수 없는 암호문만 남습니다 (종단간 암호화).
- 백업: 설정 → **🔒 암호화 백업 저장**. 동기화와 별개로 가끔 받아 두면 안전합니다.
- ⚠️ 동기화를 쓰지 않을 때는 데이터가 **앱 주소(도메인)별로** 따로 저장됩니다. 주소를 바꾸기 전에 백업하세요.

> 참고: PWA 자체에는 동기화 기능이 없습니다. PWA는 웹앱을 설치·오프라인 실행하게 해 주는 방식이고, 기기 간 연동은 아래 동기화 서버가 담당합니다.

## 동기화 서버 만들기 (Cloudflare 무료, 약 5분, 1회만)
1. https://dash.cloudflare.com 가입/로그인
2. **Storage & Databases → KV → Create** → 이름 `metalcal-vault` 로 만들기
3. **Workers & Pages → Create → Worker**(Hello World로 시작) → 이름 `metalcal-sync` → Deploy
4. 만든 Worker에서 **Edit code** → 기존 코드를 지우고 `sync-worker/worker.js` 내용 전체 붙여넣기 → **Deploy**
5. Worker → **Settings → Bindings → Add → KV namespace** → 변수 이름 **`VAULT`**, 네임스페이스 `metalcal-vault` 선택 → 저장(Deploy)
6. Worker 주소(`https://metalcal-sync.내계정.workers.dev`)를 브라우저로 열어 `{"ok":true,"app":"metalcal-sync"}` 가 보이면 완료
   (대시보드 메뉴 이름은 시기에 따라 조금 다를 수 있습니다)

### 기기 연결
- **첫 기기**: 설정 → 기기 간 동기화 → 서버 주소 입력 → **새 동기화 시작** → 20자리 동기화 코드가 생성됨 (자동 복사)
- **다른 기기**: 같은 서버 주소 입력 → **다른 기기의 코드 입력** → 코드 입력
- 이후 변경 2초 뒤 자동 업로드, 앱을 열 때·1분마다 자동으로 맞춥니다. 오프라인에서 한 변경은 연결되면 반영됩니다.
- 동기화 코드 = 암호 열쇠입니다. 잃어버리면 서버 데이터는 복구 불가(각 기기 데이터는 유지), 남에게 알려지면 일정이 노출됩니다.
- 무료 한도(KV 쓰기 하루 1,000회)는 개인 사용에 충분합니다.

## USB 휴대용 실행 (서버 없이 내 컴퓨터·USB에 저장)
`metalcal-usb.zip` 압축을 USB에 풀고:
- **윈도우**: `start-windows.bat` 더블클릭 (설치 불필요, 내장 PowerShell 사용)
- **맥**: `start-mac.command` 더블클릭 (처음엔 오른쪽 클릭 → 열기)

브라우저에 `http://localhost:8765`가 열리고, 모든 데이터가 **USB 폴더의 `data/metalcal-data.json`**에 저장됩니다(변경 즉시 저장, 하루 1개 자동 백업 `data/backup/`, 최근 30개).
USB를 다른 컴퓨터에 꽂고 같은 파일을 실행하면 그대로 이어집니다. 설정 → USB 휴대용 저장에서 **파일 비밀번호**를 정하면 파일이 AES-256으로 암호화됩니다(권장).
실행 창(검은 창/PowerShell)이 떠 있는 동안 파일에 저장됩니다. 창을 닫은 채 앱을 쓰면 그 컴퓨터에만 임시 저장되었다가, 다음에 실행 파일을 켜면 파일에 합쳐집니다.
웹·휴대폰과도 맞추려면 USB 버전에서도 설정 → 기기 간 동기화에 같은 코드를 입력하세요.


HTTPS 주소가 있어야 휴대폰에 설치할 수 있습니다.

1. **Cloudflare Pages (권장)** — 무료, 트래픽 무제한, 저장소 공개 불필요
   - dash.cloudflare.com → Workers & Pages → Create → Pages → **Upload assets**
   - 이 폴더(index.html이 있는 폴더)를 통째로 끌어다 놓기 → `https://이름.pages.dev` 주소 발급
2. **GitHub Pages** — 무료 계정은 저장소를 공개해야 함 (코드만 공개되고 일정 데이터는 공개되지 않음)
3. **Netlify Drop** — app.netlify.com/drop 에 폴더를 끌어다 놓기

수정 후 다시 올릴 때는 `sw.js`의 `VERSION` 값을 올려 주세요. 앱을 다시 열면 새 버전이 적용됩니다.

## 기능
- 메탈(티타늄 다크 / 실버 라이트) UI
- **날짜 표시(휴가·연차·기념일 등)**: 날짜 칸 자체에 색 띠와 이름으로 기록되어 일정 막대와 겹치지 않음
- **색상별 행 정렬**: 월간/주간 종일 영역에서 같은 색상 일정은 같은 행에 일렬로 배치 (설정에서 색상 순서 = 행 순서)
- **길게 눌러 이동**: 일정을 길게 누르면 들어올려져 원하는 날짜·시간으로 이동. 주/일 보기에서 하단 손잡이로 길이 조절. 마우스는 바로 끌기도 가능
- **검색**: 과거/미래 키워드 검색 (제목·메모·장소·#태그, 여러 단어 AND), 색상 필터
- **색상·태그 분류**: 사이드바에서 색상별 표시/숨김, 태그 필터
- **스마트 반복**: 매일/평일/매주(요일 선택)/격주/N주마다/매월 날짜·N번째 요일·마지막 요일·말일/매년, 종료일·횟수, 주말·공휴일 건너뛰기, 할 일 ‘완료 후 N일 뒤 다시’, 반복 일정의 ‘이 일정만 / 이후 / 전체’ 수정·삭제
- **자연어 빠른 추가**: `내일 오후 3시 회의 #업무 !1`, `매주 월수금 7시 헬스`, `다음주 금요일 10:30~12시 미팅`, `매월 25일 카드 결제`
- **보기**: 연 · 월 · 주 · 일 · 일정 목록
- **가계부** (편한 가계부 방식, 수기 입력): 수입·지출·이체, 분류/소분류(설정에서 편집), 자산(현금·은행·카드·저축·대출), 금액 계산식(12000+3500), 반복 거래(매주·매월·매년 자동 기록), 한 달 시작일(월급일) 설정
  - 탭: **일일**(날짜별 내역·전체 기간 검색) · **달력**(날짜별 수입/지출) · **월별**(1년 비교) · **통계**(분류별 비율·지난달 대비·소분류) · **예산**(분류별 예산·하루 권장 지출) · **자산**(자산/부채/순자산, 카드 이번 달 사용액) · CSV(엑셀) 내보내기
  - 카드값 납부는 ‘이체’(통장 → 카드)로 기록하면 잔액이 맞습니다
- **기록장**: 일정과 별개로 자유롭게 쓰는 메모장. 자동 저장, 📌 고정, 날짜 지정, ‘📔 오늘’로 날짜별 일기 바로 열기. 태그는 직접 붙이거나 본문에 `#태그`를 쓰면 자동 분류 → 태그별로 걸러 보기, 기록 검색, 전체 검색(🔍)에도 함께 표시, 기기 간 동기화 포함
- **목표 영역**: 금융·재정 / 본업·커리어 / 부업·사업 / 건강·체력 / 자기계발·학습 / 관계·가족 / 여가·취미 / 마음·생활 — ‘삶의 수레바퀴(Wheel of Life)’ 8영역에 본업·부업을 분리해 구성. 목표 화면의 **영역별 균형**, 영역 필터(캘린더·목록·매트릭스·목표에 공통 적용)
  - 핵심 결과를 **가계부와 자동 연동**: 순자산, 특정 통장 잔액, 이번 달 저축액·수입·지출, 분류별 누적(예: 부수입) — 기록하면 목표 진척이 저절로 올라감
- **목표 설계** (5단계): ① 현황 파악(주관적 자료·객관적 자료) → ② 핵심 과제(문제·원인·근거) → ③ 목표(SMART 점검 + 숫자로 확인하는 핵심 결과/OKR) → ④ 실행 계획(장애물에 대한 ‘만약 ~하면, 나는 ~하겠다’ 계획, WOOP) → ⑤ 평가(달성·부분 달성·미달성, 정기 점검). 목표 화면에서 바로 연결된 할 일을 만들 수 있음
- **아이젠하워 매트릭스 + 👍 추천**: ‘꼭 이뤄야 할(필수)’ 목표에 연결(또는 키워드 일치)되면 중요, 마감 2일 이내·기한 지남·목표 기한 임박이면 긴급으로 판단해 사분면을 추천. 추천과 일치하면 👍, 다르면 ‘👍 Q2’ 버튼으로 한 번에 이동, ‘추천대로 정리’로 일괄 적용. 길게 눌러 사분면 간 이동도 가능
- **뽀모도로**: 집중/짧은 휴식/긴 휴식 시간을 화면에서 바로 설정(−/+, 프리셋, 직접 입력 1–180분), 할 일 연결(🍅 횟수 기록), 7일 통계, 알림음·진동
- 대한민국 공휴일(설·추석·대체공휴일 2025–2028 수록), 알림(앱이 열려 있을 때), ICS 가져오기/내보내기(구글·애플 캘린더 이전용), 실행 취소
- 키보드: ←/→ 이동 · T 오늘 · M/W/D/Y/L/G/E/B/P 보기 전환 (B = 가계부, R = 기록장) · N 새 일정 · / 검색

## 알아둘 점
- 알림은 서버 푸시 없이 동작하므로 **앱이 열려 있을 때** 표시됩니다. 아이폰은 iOS 16.4 이상 + 홈 화면 설치 후 알림 권한을 허용해야 합니다.
- 공휴일 데이터는 수록 연도 이후엔 고정 공휴일만 표시됩니다. 임시공휴일 등은 ‘날짜 표시’로 직접 추가하세요.

## 로컬에서 실행
```bash
python3 -m http.server 8765
```
브라우저에서 http://localhost:8765 접속.
